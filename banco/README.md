# Banco de demonstração

O laboratório real utiliza PostgreSQL e a tabela `municipios`, mas o esquema completo e os dados originais não foram exportados aqui. `estrutura-minima.sql` é **opcional** e cria apenas uma tabela simples com nomes fictícios para experimentar as consultas em um banco de testes vazio.

**Não execute este arquivo no banco original sem avaliar conflitos de nome de tabela.** Não contém dados oficiais nem reproduz a base utilizada nos exercícios.
